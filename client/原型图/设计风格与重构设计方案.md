# 🐍 《贪吃蛇》极简现代主义游戏设计规范与重构方案

> 📖 **设计溯源**：深度融合南大家园工作室（NCUHOME / 云家园 / 此间指南）的纯白极简留白哲学、人文排版与多巴胺彩色微点缀体系，将传统街机像素游戏升华为现代化、呼吸感与高级感并存的移动优先 Web 游戏产品。  
> 🌟 **核心品牌色**：天青蓝（经典主色 **`#66CCFF`**）+ 深天蓝强调（**`#0099FF`**）。

---

## 🎨 一、 核心设计美学与视觉哲学 (Aesthetics & Philosophy)

1. **纯白极简基调 (Pure White Baseline)**：
   - 彻底摒弃传统游戏暗黑压抑或高饱和杂乱背景，采用 **纯白 (`#FFFFFF`)** 作为游戏主舞台；
   - 全面移除白色卡片阴影，依赖 **极薄浅灰细边线 (`#E2E8F0`)** 和 **几何胶囊圆角** 划分层次，呈现如现代艺术品般的方寸呼吸感。

2. **南大家园 NCU HOME 水印与多巴胺四色微徽标**：
   - 背景融入浅灰大字号 **`NCU`** 与 **`HOME`** 艺术水印（`pointer-events-none` 穿透）；
   - 水印上方点缀 **红 / 黄 / 绿 / 天青蓝 `#66CCFF`** 四色活力微圆点，兼具青春朝气与现代严谨。

3. **人文排版与点睛单字 (Humanistic Typography & Rhythm)**：
   - **主标引言**：顶部以人文单行大字号 **“方寸之<span style="color:#66CCFF">间</span>，重温经典。”** 为视觉引力，搭配左侧 `3px` 天青蓝 (`#66CCFF`) 竖线金句；
   - **等宽几何粗体数字**：得分、用时、排行榜名次统一使用等宽几何数字徽标，紧凑干练。

4. **矢量纯粹与无 Emoji 界面原则 (Vector Pure & Zero Clutter)**：
   - 全局界面 100% 采用 **Lucide 线性矢量图标 (`stroke-width: 1.8`)**，杜绝 Emoji 带来的色彩噪点与视觉杂乱；
   - 画布内蛇身、果实采用极简几何圆角（Pill Radius），兼具经典韵味与现代丝滑质感。

## 🧩 三、 贪吃蛇各模块交互组件契约 (Game Component Specs)

### 1. 游戏导航顶栏 (`Header`)
- **外观**：纯白底板 + 极薄浅灰细边线 `border border-[#E2E8F0]`，大圆角 `rounded-2xl`；
- **左侧**：天青蓝 (`#66CCFF`) 极简贪吃蛇徽标 + 粗体 `贪吃蛇` + 胶囊 `经典版` 标签；
- **右侧**：新手指南按钮（罗兰紫悬浮反馈）+ 8-bit 音效开关 + 玩家身份胶囊与退出。

### 2. 状态胶囊栏 (`ScoreCompositeBox`)
- **四段式复合软底胶囊**：
  - **得分（红）**：`bg-rose-50 border-rose-100` + 红字
  - **长度（绿）**：`bg-emerald-50 border-emerald-100` + 绿字
  - **用时（紫）**：`bg-purple-50 border-purple-100` + 紫字
  - **速度（蓝）**：`bg-[#EBF8FF] border-[#66CCFF]/50` + 蓝字

### 3. 极简现代画布舞台 (`GameBoard Canvas`)
- **容器规格**：黄金视口适配（24×24 格，手机端自适应缩放）；
- **外框美学**：纯白底板 + `border border-[#E2E8F0]` + `rounded-2xl` 纯平面化设计；
- **触觉微震动 (Haptic Feedback)**：吃普通果 (12ms)、金色果 (两次)、死亡 (40ms)；
- **金果限时进度条**：幸运果出现时，在画布上沿投射一条 `#66CCFF` 天青蓝倒计时流光。

### 4. 移动端极简微型十字控制台 (`VirtualDPad`)
- **展示策略**：PC 键盘端自动隐藏，触屏设备自适应浮现；
- **响应优化**：配置 `touch-action: manipulation` 与 `user-select: none`，消除 300ms 触控缩放延迟。

### 5. 沉浸式战绩排行榜 (`Leaderboard`)
- **结构规范**：
  - 标题栏：`Top 10 风云榜` + 刷新按钮；
  - 1~6 专属多巴胺彩色几何数字徽标；
  - 当前玩家高亮行：`bg-[#F6FBFF] border border-[#66CCFF]/40 text-[#0099FF]`；
  - 战绩评语：底部天青蓝微边卡片展示 *“个人最高纪录：XX分 · 超越 XX% 玩家”*。

## 📐 四、 工程与架构落地 (Engineering Specs)

1. **单一一级 `.gitignore`**：整个代码库仅在根目录保留权威 `.gitignore`，杜绝子目录分散维护；
2. **优雅停机 (Graceful Shutdown)**：后端 Go API 服务采用 `http.Server` + 信号监听安全退出；
3. **免密凭据持久化**：玩家凭据本地安全缓存，刷新页面自动恢复登录；
4. **编译与打包质量**：ESLint 严格 0 错误 0 警告，Next.js 静态打包 100% 成功。
