# 🐍 《贪吃蛇》极简现代主义游戏设计规范

> 📖 **设计理念**：南大家园纯白留白哲学 + 天青蓝核心色 (`#66CCFF` / `#0099FF`) + 多巴胺彩色微点缀体系。

---

## 🎨 一、 核心视觉美学

1. **纯白留白与轻边线**：采用纯白 (`#FFFFFF`) 与浅灰 (`#F8FAFC`) 底板，移除厚重阴影，改用极薄细边线 (`#E2E8F0`) 与胶囊大圆角 (`rounded-2xl` / `rounded-3xl`)。
2. **专属极简水印**：浅灰 `NCU HOME` 艺术水印与四色（蓝/黄/绿/粉）活力微徽标。
3. **人文排版**：主标引言 `方寸之间，重温经典。`（搭配 `#66CCFF` 单字点睛与 `3px` 竖线）。
4. **矢量纯粹**：全界面 100% 采用 Lucide 线性矢量图标，杜绝 Emoji 噪点。

---

## 🌈 二、 游戏设计令牌与色彩系统

### 1. 核心品牌色
| Token 变量 | 色值 | 用途映射 |
| :--- | :--- | :--- |
| `--primary-cyan` | `#66CCFF` | 核心天青蓝（蛇头主色、金果进度条、竖线、点睛单字） |
| `--primary-dark` | `#0099FF` | 深天蓝强调（主要 CTA 按钮、激活态、高亮字） |
| `--primary-light` | `#EBF8FF` | 浅天蓝底色（速度胶囊背景、战绩徽标底色） |

### 2. 多巴胺微色彩
| 角色 | 色值 | 应用场景 |
| :--- | :--- | :--- |
| **珊瑚红** | `#EF4444` / `#FEE2E2` | 得分胶囊、红苹果（100% 存在，吃后清空栅栏）、No.2 徽标 |
| **翡翠绿** | `#10B981` / `#DCFCE7` | 长度胶囊、No.3 徽标 |
| **暖琥珀金** | `#F59E0B` / `#FEF3C7` | 榜首 No.1 徽标、金色幸运果（25% 概率限时 8s，+30 分保留栅栏） |
| **罗兰紫** | `#8B5CF6` / `#EDE9FE` | 用时胶囊、No.4 徽标、新手指南 |
| **活力青** | `#0284C7` / `#0891B2` | No.5~6 徽标、按键激活态 |
| **速度梯度** | `122ms ~ 61ms` | 基础速度 0.9x 平滑递增至 2.0x 极速 |

### 3. 榜单等宽几何数字徽标 (1~10)
名次采用 `22px × 22px` 粗体几何徽标：
- **No.1 金**：`#FEF3C7` / `#D97706`
- **No.2 红**：`#FEE2E2` / `#EF4444`
- **No.3 绿**：`#DCFCE7` / `#16A34A`
- **No.4 紫**：`#EDE9FE` / `#7C3AED`
- **No.5 蓝**：`#E0F2FE` / `#0284C7`
- **No.6 青**：`#CFFAFE` / `#0891B2`
- **No.7~10 灰**：`#F1F5F9` / `#64748B`

## 🧩 三、 核心组件交互规范

1. **`Header.tsx` 导航顶栏**：品牌徽标 + 玩家身份与最高分徽标 + 8-bit 音效开关 + 规则指南弹窗 + 退出。
2. **`Board.tsx` 画布舞台**：
   - 顶部四段式状态胶囊（得分/长度/用时/速度）；
   - 蛇身相邻胶囊连结桥 + 灵动双圆高光眼珠；
   - 粒子微爆发、向上浮动 Combo 飘字与死亡 8 帧微震屏；
   - 移动端微型虚拟十字键 + 全屏滑动手势。
3. **`Leaderboard.tsx` 风云榜**：Top 10 排行流水 + 当前玩家高亮行 + 动态超越百分比评语。
4. **`Login.tsx` 登录/注册**：双字段卡片，未注册账号直接免密自动注册入库。
5. **`Tutorial.tsx` 新手指南**：4 条核心规则与冲榜技巧图文卡片。
