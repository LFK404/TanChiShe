# 🐍 《贪吃蛇》极简现代主义游戏设计规范

> 📖 **设计理念**：南大家园纯白留白哲学 + 天青蓝核心色 (`#66CCFF` / `#0099FF`) + 多巴胺彩色微点缀体系。

---

## 🎨 一、 核心视觉美学

1. **纯白留白与轻边线**：采用纯白 (`#FFFFFF`) 与浅灰 (`#F8FAFC`) 底板，移除厚重阴影，改用极薄细边线 (`#E2E8F0`) 与胶囊大圆角 (`rounded-2xl` / `rounded-3xl`)。
2. **专属极简水印**：浅灰 `NCU HOME` 艺术水印与四色（蓝/黄/绿/粉）活力微徽标。
3. **人文排版**：主标引言 `方寸之间，重温经典。`（搭配 `#66CCFF` 单字点睛与 `3px` 竖线）。
4. **南大家园多巴胺微拟态图标规范（NCU Squircle Glyph System）**：
   - **超椭圆柔和底座（Squircle Base）**：28% 连续曲率平滑超椭圆，杜绝生硬直角与机械圆弧；
   - **灵动不规则曲线（Fluid Bezier Silhouette）**：采用非对称高阶贝塞尔曲线构建自然亲和的符号剪影，杜绝千篇一律的通用模板图标；
   - **主基调与辅助色双色碰撞（Multi-tone Harmony）**：每一个图标均由专属主基调色（如南大天青、流金、翠绿、紫罗兰）辅以高光或第二对比色（如土星的金身蓝环、小蛇的天青蓝与明眸高光），形成活泼多彩的视觉层次；
   - **暗态至亮态双阶进化（Dual-State Evolution）**：
     - **未解锁/休眠态**：雾霾灰 `#B8C5D3` 超椭圆底板与浅灰低透明度图案，安静克制；
     - **已解锁/激活态**：瞬间点亮高饱和多色微渐变，辅以同色系 0.25 Alpha 柔和发光光晕（Halo）与果冻弹性微跳；
   - **绝无通用 Emoji**：全套采用纯矢量代码级渲染，轻盈、锐利、零锯齿。
5. **视听触三位一体交互**：
   - **多层级触觉反馈**：强力/轻柔/关闭三档切换，联动连击阶梯脉冲、极速狂飙心跳搏动与 UI 刻度吸附；
   - **温润声学微雕与沉水透传**：Web Audio 原生合成器接入 2600Hz 低通滤波器（Low-pass BiquadFilter），消除尖锐毛刺；空格暂停时滤波截止频率平滑降至 360Hz 沉水磨砂声场，恢复时清澈浮回；
   - **主机级双轨 BGM**：大厅温馨吉他与局内元气音乐智能转场，高光 Jingle 智能音频避让（Audio Ducking）与 55Hz 低频心跳脉冲。
6. **走位几何抽象生成艺术（Generative Trajectory Art）**：
   - 将玩家全局按键轨迹转化为 900×1200 像素的高清算法艺术海报，结合 Chaikin 样条平滑、时序色彩流光与走位热力密度叠加，展现瑞士国际主义极简版式美学与分享骄傲。

## 🌈 二、 游戏设计令牌与色彩系统

### 1. 核心品牌色
| Token 变量 | 色值 | 用途映射 |
| :--- | :--- | :--- |
| `--primary-cyan` | `#66CCFF` | 核心天青蓝（蛇头主色、金果进度条、竖线、点睛单字、艺术轨迹起始段） |
| `--primary-dark` | `#0099FF` | 深天蓝强调（主要 CTA 按钮、激活态、高亮字、艺术轨迹中盘段） |
| `--primary-light` | `#EBF8FF` | 浅天蓝底色（速度胶囊背景、战绩徽标底色） |

| :--- | :--- | :--- |
| **珊瑚红** | `#EF4444` / `#FEE2E2` | 得分胶囊、红苹果（100% 存在，吃后清空栅栏）、No.2 徽标、终局同心落幕印 |
| **翡翠绿** | `#10B981` / `#DCFCE7` | 长度胶囊、No.3 徽标、普通吃果印记 |

| **速度梯度** | `140ms ~ 70ms` | 基础速度 1.0x (Lv.0 0~69分) 平滑非线性递增至 2.0x 极限 (≥1160分) |

### 3. 3秒极速连击与阶梯加分算法
- **全果品纳入时钟**：红苹果与金色幸运果吃掉均刷新 3000ms 连击时钟并递增连击数；
- **阶梯额外加分公式**：
  - 连击数 $\le 2$：无额外加分（2 连击时激活蛇身耀金多巴胺流光脉冲与提示）；
  - 连击数 $\ge 3$：单次吃果额外斩获 $(combo - 2) \times 5$ 分（第 3 次 +5 分、第 4 次 +10 分、第 5 次 +15 分……上不封顶）；
- **濒危预警频闪**：剩余时间不足 1 秒时，蛇身与蛇头呈现急促橙红高频呼吸警示，蛇头正上方显示 3 秒圆环倒计时微弧。

### 4. 0.1x 平滑非线性阶梯提速与即时动效
- **基础速度**：`140ms`（约 7.1 格/秒，温和从容开局）；
- **极限速度**：`70ms`（2.0x 极限狂飙封顶）；
- **分段阶梯与增量递增规律**：
  - **Lv.0** (1.0x, 140ms): 0 ~ 69 分（专属 70 分平缓起步区）；
  - **Lv.1** (1.1x, 127ms): 70 ~ 139 分（跨度 70 分）；
  - **Lv.2 ~ Lv.5** (1.2x ~ 1.5x): 跨度较上一档递增 +10 分（80 ➔ 90 ➔ 100 ➔ 110 分）；
  - **Lv.6 ~ Lv.9** (1.6x ~ 1.9x): 跨度较上一档递增 +20 分（130 ➔ 150 ➔ 170 ➔ 190 分）；
  - **Lv.10** (2.0x, 70ms): $\ge 1160$ 分（破千分极限封顶）；
- **速度变化全栈即时提示体系**：
  - *局内微飘字*：每当移速跨档提升时，蛇头上方弹出轻灵天青浮字 `⚡ X.Xx`；
  - *顶部胶囊弹性高光*：顶部“速度”胶囊在变速瞬间触发 `scale-105 ring-2 ring-[#0099FF]/40` 柔和微缩放高光与吸附触感；
  - *全屏里程碑荣誉 Toast*：在 1.3x、1.5x、1.7x、2.0x 关键进阶节点触发多巴胺悬浮弹窗。

## 🧩 三、 核心组件交互与微动效规范

1. **`Header.tsx` 综合控制中心**：品牌徽标 + 玩家身份与最高分胶囊 + BGM/SFX 双轨独立音量滑块 + 触感三档切换 + 殿堂/指南弹窗 + 退出。
2. **`Board.tsx` 画布舞台与微动效矩阵**：
   - **蛇头情绪微表情系统**：
     - *濒死惊慌（Panic Glance）*：正前方 1 格遇死角时，双眼瞪大（2.6px）、瞳孔骤缩（0.75px）并施加 30Hz 高频微颤抖；
     - *吃果满足（Satisfied Blink）*：吃果后 220ms 内双眼化为两条温润月牙笑弧；
     - *落幕闭目（Rest in Peace）*：对局结束定格时双眼闭合为淡灰细线；
   - **死路余温石化冷却动效**：蛇尾蜕下栅栏在前 180ms 内由浅天青蓝柔和冷却石化为浅灰色，消除方块突兀刷出感；
   - **等宽数字防抖（Tabular Numbers）**：全局胶囊数值注入 `tabular-nums` 严格等宽对齐，彻底消除数字变动引发的布局抽搐；
   - **蛇身物理吞咽传导波**：吃果时产生沿蛇身逐节传导的 1.24x 弹性隆起波；
   - **果实果冻微弹跳**：红果与金果生成时 220ms 内由 0% ➔ 132% ➔ 100% 弹性回弹；
   - **残留栅栏粉尘瓦解**：吃红果清空栅栏时产生 8 颗细腻粉尘瓦解消散微粒子；
   - **连击浮字弹性缩放**：微浮字生成时带有 `scale: 1.4 ➔ 1.0` 的贝塞尔弹性回弹；
   - **破纪录四色欢庆礼花**：高分结算时从画布两侧向上喷发天青、绿、红、金四色彩纸；
   - **运动残影与视线预瞄**：极速狂飙运动残影与转向缓冲队列视线提前预瞄；
   - **移动端多模自适应**：全屏滑动手势（Swipe）+ 微型虚拟十字键。
3. **`TrajectoryCardModal.tsx` 走位几何艺术海报生成系统**：
   - **Chaikin 2阶样条平滑**：取拐角 1/4 和 3/4 倒角插值，将 90° 机械折角平滑为流体现代样条曲线；
   - **时序色彩映射**：0%~30% 天青蓝、30%~65% 深天蓝、65%~88% 连击金、88%~100% 暮光紫；
   - **走位热力半透明叠合**：半透明线宽在辗转腾挪密集区域自然堆叠出走位能量热力层；
   - **瑞士国际主义版式**：900×1200 像素高清离屏渲染，温润纸质灰白底色、十字定位准星、等宽四格战绩看板与 28% 超椭圆南大家园拟物朱红小篆印；
   - **交互支持**：支持原生 `ClipboardItem` 图片复制与高清 PNG 保存下载。
4. **`Leaderboard.tsx` 风云榜与录像剧场**：Top 10 排行流水 + 当前玩家高亮行 + 一键观摩走位电竞重放（支持 1.0x / 1.5x / 2.0x 倍速切换）。
5. **`Achievements.tsx` 成就殿堂**：24 枚四阶梯南大家园微拟态成就徽章，支持暗态静默与亮态点亮。
6. **`Login.tsx` 极简登录**：双字段卡片，未注册账号直接免密自动注册入库。
7. **`Tutorial.tsx` 极简指南**：5 条核心机制（死路、红苹果、金果、3秒连击与全端操控）。

## 📐 四、 工程质量与安全规范

1. **单一一级 `.gitignore`**：统一根目录权威维护，严防环境凭据外泄。
2. **Level 3 物理重放防作弊**：Mulberry32 确定性种子 + Go 后端 1ms 无头物理重放引擎亲自演算真实战绩（包含 3 秒连击时钟与阶梯加分一致性演算），杜绝前端数据篡改与超速外挂。
3. **安全令牌与行级安全**：无状态 HMAC 会话令牌握手，滑动窗口限流器（单 IP 20次/秒），Supabase RLS 策略。
4. **质量准则**：严格 0 ESLint 报错，100% SSG 静态导出，Go 单元测试全量 PASS。
