# 🐍 《贪吃蛇》极简现代主义游戏设计规范

> 📖 **设计理念**：NCU HOME 纯白留白哲学 + 天青蓝核心色 (`#66CCFF` / `#0099FF`) + 多巴胺彩色微点缀体系 + 纯代码级矢量极简规范。

## 🎨 一、 核心视觉美学

1. **纯白留白与轻边线**：采用纯白 (`#FFFFFF`) 与浅灰 (`#F8FAFC`) 底板，移除厚重阴影，改用极薄细边线 (`#E2E8F0`) 与胶囊大圆角 (`rounded-2xl` / `rounded-3xl`)。
2. **专属极简水印**：浅灰 `NCU HOME` 艺术水印与四色（蓝/黄/绿/粉）活力微徽标。
3. **人文排版**：主标引言 `方寸之间，重温经典。`（搭配 `#66CCFF` 单字点睛与 `3px` 竖线）。
4. **多巴胺微拟态图标规范（NCU Squircle Glyph System）**：
   - **超椭圆柔和底座（Squircle Base）**：28% 连续曲率平滑超椭圆，杜绝生硬直角与机械圆弧；
   - **灵动不规则曲线（Fluid Bezier Silhouette）**：采用非对称高阶贝塞尔曲线构建自然亲和的符号剪影，杜绝千篇一律的通用模板图标；
   - **主基调与辅助色双色碰撞（Multi-tone Harmony）**：每一个图标均由专属主基调色（如天青蓝、流金、翠绿、紫罗兰）辅以高光或第二对比色（如土星的金身蓝环、小蛇的天青蓝与明眸高光），形成活泼多彩的视觉层次；
   - **暗态至亮态双阶进化（Dual-State Evolution）**：
     - **未解锁/休眠态**：雾霾灰 `#B8C5D3` 超椭圆底板与浅灰低透明度图案，安静克制；
     - **已解锁/激活态**：瞬间点亮高饱和多色微渐变，辅以同色系 0.25 Alpha 柔和发光光晕（Halo）与果冻弹性微跳；
   - **绝无通用 Emoji**：全套采用纯矢量代码级渲染，轻盈、锐利、零锯齿。
5. **深空墨蓝夜间模式（OLED Deep Dark）**：
   - 导航栏纯矢量超椭圆日/月切换微拟态按钮；全局注入深空墨蓝变量 `#0A0F1D`；
   - Canvas 离屏背景借助 MutationObserver 实时热重绘深邃网格，保护夜间视力。
6. **视听触三位一体交互**：
   - **多层级触觉反馈**：强力/轻柔/关闭三档切换，触觉职责严格单向分层，杜绝重复震颤；
   - **温润声学微雕与沉水透传**：Web Audio 原生合成器接入 2600Hz 低通滤波器，消除尖锐毛刺；空格暂停时滤波频率降至 360Hz 沉水磨砂声场，恢复时清澈浮回；接入挂起态自愈恢复；
   - **主机级双轨 BGM**：大厅温馨吉他与局内元气音乐智能转场，高光 Jingle 智能音频避让（Audio Ducking）与 55Hz 低频心跳脉冲。
7. **走位几何抽象生成艺术（Generative Trajectory Art）**：
   - 将玩家全局按键轨迹转化为 900×1200 像素的高清算法艺术海报，结合 Chaikin 样条平滑、时序色彩流光与走位热力密度叠加，展现瑞士国际主义极简版式美学与分享骄傲。

### 3. 3秒极速连击与阶梯加分算法 (黄金能量行波)
- **全果品纳入时钟**：红苹果与金色幸运果吃掉均刷新 3000ms 连击时钟并递增连击数；
- **分级呈现与阶梯额外加分公式**：
  - **连击数 $\le 2$**：无额外加分，吃果仅微浮字提示 `+10 (2连击)`，不激活全蛇身强烈流光，保证初期转弯与密集走位专注；
  - **连击数 $\ge 3$**：激活全蛇身 380ms 黄金能量行波（Fluid Golden Wave）与金光流动描边（波峰璀璨亮金、波腰天青蓝、波谷深蓝流畅交织，找回电竞飞驰感），单次吃果额外斩获 $(combo - 2) \times 5$ 分（第 3 次 +5 分、第 4 次 +10 分、第 5 次 +15 分……上不封顶）；
- **濒危预警微提示**：剩余时间不足 1 秒时，蛇身呈现温和暖橙提示，蛇头正上方显示 3 秒圆环倒计时微弧。

## 🧩 三、 核心组件交互与微动效规范

1. **`Header.tsx` 综合控制中心**：品牌徽标 + 玩家身份与最高分胶囊 + BGM/SFX 双轨独立音量滑块 + 触感三档切换 + 纯矢量夜间模式日/月切换 + 殿堂/指南弹窗 + 退出。
2. **`Board.tsx` 画布舞台与微动效矩阵**：
   - **极简外置流光导轨（Bonus Time Rail）与绝对零物理位移**：移出 Canvas 视界，采用高度固定为 4px 的流光细槽，金果显隐物理占位恒定，彻底消除棋盘 Canvas 抖动位移；起步前完全冻结，棋盘视野 100% 清透；
   - **物理步序时钟全面对齐（Simulation Tick Alignment）**：金果寿命、临期警报频闪（$\le 3.0$s 且非起步等待）与 3 秒连击时钟完全由物理步序驱动，彻底杜绝现实时钟在暂停与起步时的脱节漂移；
   - **全景深空墨蓝夜间模式（OLED Deep Dark）**：Header 顶栏、棋盘遮罩、控制台、音量面板、战绩结算与底色全面自适应 `#0A0F1D` 深空色系；
   - **纯净防重叠双轨 BGM**：重开对局瞬间自动清退死亡结算延时大厅音轨，严密杜绝音轨重叠共播竞态，切局时滤镜频率强制复位 2600Hz 清澈声场；
   - **高分屏 DPR 矢量级超清渲染**：Canvas 物理像素按 `window.devicePixelRatio` 动态缩放缓冲区，配合绘图上下文缩放，消除视网膜屏模糊锯齿；
   - **暂停态动效物理定格**：粒子位移、衰减、连击飘字与屏幕震颤只在 `!isPaused` 时推进，暂停时静态定格，带来极佳时空凝滞沉浸感；
   - **重开局特效缓存复位**：重新开局时自动清空粒子队列、彩纸与吞咽波，保证开局纯净；
   - **蛇身物理吞咽传导波（Organic Digestion Wave）**：进食时正弦微隆起波（40ms/节）从蛇头传导至蛇尾，内部叠加晶莹自发光核（金果炽白），具象化流体物理吞咽吞吐感；
   - **蛇头情绪微表情系统与灵动明眸微雕**：
     - *常态明眸微雕*：眼白半径由 2.2px 微放大至 2.6px，黑瞳由 1.2px 微放大至 1.45px，并点缀 0.45px 晶莹高光点，黑白分明更添灵秀与萌动；
